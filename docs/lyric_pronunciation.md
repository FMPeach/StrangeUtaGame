# 中文和韩文歌词注音

## 中文多音字

PinyinAnalyzer 使用现有 jieba 分词，把词组交给 pypinyin 内置词典选音；默认只输出一个读音，并不是对整句语义或原唱音频进行识别。词典以外的词、人名、歌词省略句和分词错误仍可能选错。

中文假名入口实际为「中文片假名注音」，PinyinKatakanaAnalyzer 继承相同的拼音分析结果，再转片假名，不会重新消歧。保留原有的歌曲常用口语默认音覆盖：“谁”→ shéi、“熟”→ shóu、“血”→ xiě；通过 pypinyin 的全局单字词典加载，词组仍按词典上下文选音。特殊唱法可逐处手改注音。

片假名只近似中文音值，现有长音符也是转写惯例，不表示实际音符时长或声调。

## 韩文注音

旧实现逐个音节查表，不含跨音节音变；它既不是完整 RR，也不是官方可逆逐字转写。现在先对连续韩文（含已转换的韩音汉字）做基础发音处理，再输出片假名、平假名或使用 RR 字母表的罗马音。

已处理：韵尾中和、单/双韵尾连音、部分腭化、ㅎ 脱落与送气、鼻音化、基础流音化、阻塞音后紧音化。例如 먹어 → meogeo、국물 → gungmul、신라 → silla、같이 → gachi。音变保留原字符位置及每字节奏点。

罗马音会显示规则推导的紧音化（먹다 → meoktta），这是跟唱辅助，与官方 RR 省略部分紧音化的规则有意不同。假名仍无法准确表达韩语全部元音、紧音/送气和不除阻韵尾，尾音 ク/ト/プ 不应唱成额外完整音节。

这不是完整的韩语 G2P：未做形态分析，复合词增音（如 학여울）、实词边界连音例外（如 맛있다）、词汇性紧音化、ㄺ/ㄼ 等词干例外、部分流音化例外、의 的语法读音等仍可能误判。空格、标点和未知汉字阻断音变。实际演唱中的连读、方言、弱化和刻意分音，应听原唱后手改。基于标准发音的辅助比逐字拼写更适合跟唱，但不能保证最接近每首歌。

## 依据

- [pypinyin 使用文档](https://pypinyin.readthedocs.io/zh-cn/master/usage.html)：词组输入、多音字及词典。
- [国立国语院：标准发音法](https://korean.go.kr/kornorms/regltn/regltnView.do?regltn_code=0002)：韵尾、连音、同化等。
- [国立国语院：Romanization of Korean](https://www.korean.go.kr/front_eng/roman/roman_01.do)：以标准发音为基础，以及紧音、专名和可逆转写等例外。
